# Monthly Security Review Runbook

## Review Checklist

1. capture security posture
2. review privileged access
3. review incidents
4. review vulnerabilities
5. review recent production changes
6. review backup status and latest restore evidence
7. review payout/payment anomalies
8. update monthly evidence log

## Required Registers

- access review
- vulnerability register
- incident log
- audit-log review log
- monthly evidence log
