# Incident Response Runbook

## 1. Detect

- confirm issue source
- preserve timestamp, screenshots, logs, and affected IDs

## 2. Classify

- assign severity
- identify whether payments, payouts, public data, or admin access are affected

## 3. Contain

- disable affected account or token
- pause sensitive workflow if needed
- isolate failing integration where practical

## 4. Eradicate and Recover

- patch root cause
- validate recovery
- confirm logs and financial records are consistent

## 5. Communicate

- identify affected partners or sponsors
- record internal and external communications

## 6. Review

- complete incident log
- identify corrective actions
